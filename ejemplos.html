Ejemplos de servicios en la nube

IaaS (Infraestructura como Servicio)

Amazon EC2 (AWS)

Proporciona capacidad de computación redimensionable (máquinas virtuales) en la nube.

Microsoft Azure Virtual Machines

Permite crear instancias de cómputo en la infraestructura global de Microsoft.

Google Compute Engine (GCP)

Ofrece máquinas virtuales de alto rendimiento alojadas en la infraestructura de Google.



PaaS (Plataforma como Servicio)

Heroku

Una plataforma muy popular entre desarrolladores para crear, entregar y monitorear aplicaciones web rápidamente.

Google App Engine

Plataforma sin servidor (serverless) para desarrollar y alojar aplicaciones web a escala

Microsoft Azure App Service

Servicio basado en HTTP para alojar aplicaciones web, API REST y back-ends para dispositivos móviles.



SaaS (Software como Servicio)

Google Workspace (Gmail, Docs, Drive):

Suite de productividad y colaboración alojada completamente en la nube.

Salesforce

La plataforma de gestión de relaciones con los clientes (CRM) basada en la nube más utilizada del mundo

Microsoft 365

Versión en la nube de la tradicional suite de ofimática (Word, Excel, Teams), accesible desde el navegador.
